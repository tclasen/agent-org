# Boundary Assessment schema

- Target System: organization
- Change Classification: organization
- Authorized Scope: agent-org/shared/templates/BOUNDARY_ASSESSMENT.md
- Affected Paths or Resources: agent-org/shared/templates/BOUNDARY_ASSESSMENT.md
- Owning Role: Coordinator
- Related Requirements: REQ-000001, REQ-000008, REQ-000011, REQ-000012, REQ-000013, REQ-000015, REQ-000016, REQ-000034
- Related Tasks: TASK-000002
- Approval Requirements: APP-000001; future revisions follow policies/APPROVALS.md

Copy into an authorized record/checkpoint and replace angle-bracket placeholders. This schema allocates no ID, claim, result or approval. Include the eight metadata fields with actual scope when used.

- Request: <original request reference>
- Classification: <organization|project|cross_boundary|clarification_only|status_or_information_only>
- Target Decision: <system and reason; ambiguity if any>
- Source Authority: <grant and current constraints>
- Proposed Writable Surface: <exact canonical paths/resources>
- Protected Surface: <other system and exclusions>
- Children and Approvers: <separate obligations or none>
- Baseline Snapshot: <path/hash or pending>
- Verification: <positive and negative cases/verifier>
- Outcome: <admit|clarify|blocked; not authorization itself>
- Next Action: <specific safe action>
