## Procedure

1. Freeze exact baseline/candidate head/tree, dirty inventory, input/instruction/policy/evaluator identities and evidence hashes. Check task criteria and system scopes; preserve user/untracked/nested changes.
2. Admit fresh Reviewer without implementation authorship. Reviewer loads accepted criteria and pinned evidence, reruns meaningful allowed checks and verifies behavioral results plus boundaries. Distinguish deterministic fixtures/live workers/external CI; missing evidence is not pass.
3. Record criterion outcomes, failures and bounded recommendation. Organization needs independent Chief of Staff approval autonomously; project needs recorded project authority. Implementer cannot review/approve. Cross-boundary children and integration each get independent outcome checks.
4. Prepare scoped atomic commits/PR under current grant and verified repository identity. Separate organization, project and host integration changes. PR links problem/result, requirements, scope, tested candidate, checks and limits. No force push or bypass.
5. Check current host requirements, CI/review threads and exact head before allowed merge. Changed candidate or evidence invalidates affected review/approval and repeats relevant checks. Verify merged content/revision and preserve provenance.
6. Coordinator reconciles original intent, child/integration acceptance and effects, updates task state/evidence and gives concrete outcome/limits. Mismatch reopens work. Operator final installation acceptance remains separate.
