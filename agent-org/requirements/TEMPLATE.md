# Requirement template

Replace tokens with Coordinator-allocated identifiers before registration. Preserve source authority and accepted revisions.

- ID: REQ-<allocated>
- Target System: organization | project | cross_boundary
- Change Classification: same as Target System
- Authorized Scope: exact authorized paths/resources
- Affected Paths or Resources: exact paths/resources
- Owning Role: accountable owner
- Related Requirements: referenced IDs or none
- Related Tasks: task IDs or none
- Approval Requirements: grant IDs or pending
- Status: proposed
- Revision: 1
- Source: canonical user/specification/issue reference
- Authority: requirement owner
- Supersedes: none

## Requirement

Observable obligation and rationale. Mark inferences explicitly.

## Acceptance criterion

Allocated AC identifier, expected observation, verifier, evidence and pass/fail/unknown rule.

## Cross-boundary obligations

When applicable: organization obligation, project obligation and integration acceptance separately.

## Verification

Actual evidence only; not run is not pass.
