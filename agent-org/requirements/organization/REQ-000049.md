# Remote main is the completion boundary

- ID: REQ-000049
- Target System: organization
- Change Classification: organization
- Authorized Scope: agent-org/**
- Affected Paths or Resources: agent-org/**
- Owning Role: Coordinator
- Related Requirements: REQ-000049
- Related Tasks: TASK-000051
- Approval Requirements: APP-000013

- Status: accepted operator requirement

All organization and managed-project changes require verified presence on the owning remote main branch before completion/acceptance. Tests, review, local commits, pushed branches and open PRs are intermediate states. Record remote identity, PR, merged commit and fetched-main containment or equivalent content verification for squash/rebase. Outstanding changes must have an owner and next action; unavailable authority or failed checks leave delivery pending. Historical local-only acceptance is not current delivery acceptance.
