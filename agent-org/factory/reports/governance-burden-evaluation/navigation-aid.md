# Advisory navigation aid — experimental task material

This aid grants no authority and replaces no current instruction. Use the canonical sources to resolve obligations.

Start with the operator's actual requested action and existing authority, then use the matching route in AGENTS.md. Distinguish an informational answer, planning, an authorized instruction edit, implementation, review, and delivery. Open known relevant sources directly and stop expanding once scope, authority, procedure and acceptance are understood.

Navigation pointers:

- Action classification and system boundaries: policies/SCOPE_BOUNDARIES.md and policies/AUTHORITY.md.
- Feature/build authority and changed responsibilities: policies/PLANNING.md.
- Role mismatch: policies/ROUTING.md.
- An observed failure or proposed improvement: policies/SELF_IMPROVEMENT.md.
- Review independence: policies/APPROVALS.md.
- Completion and ordinary delivery: policies/ACCEPTANCE.md.
- Model metadata versus requested configuration: policies/MODEL_SELECTION.md.
- Worker state and capacity: policies/RESOURCE_BUDGETS.md.
- Minimal retrieval and exposed comparisons: shared/CONTEXT_MANAGEMENT.md.

State the supported next action and any actual blocker. Separate observed facts, reports, inference and unknowns. A navigation pointer is not an instruction to load every linked source.
