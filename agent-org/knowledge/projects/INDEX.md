# Project-local enrollment records

This directory contains generic documentation templates only. Do not add project names, URLs, profiles, opaque routing pointers, inventories or installation bindings. Discover current repositories from authorized runtime scope and keep authority, decisions and knowledge in each owning project. Store authorized private coordination outside the reusable repository.
