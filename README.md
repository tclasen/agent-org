# agent-org

A Markdown-first organization for coordinating AI agents in Codex. It gives agents clear roles, scoped tasks, durable context, independent review, and a shared process for planning, delivery, and evidence-based improvement. It uses native Codex workers and keeps project authority and Git histories separate.

See [agent-org/README.md](agent-org/README.md) for the organization map and [agent-org/AGENTS.md](agent-org/AGENTS.md) for operating instructions.

## Install in your project

Paste this into Codex from your project's root:

```text
Install agent-org from https://github.com/tclasen/agent-org into this project. Inspect its instructions, adapt the reusable roles and workflows to this repository, and add the root AGENTS.md startup bridge while preserving existing instructions. Initialize fresh project-specific state and authority; do not inherit the source repository's approvals, task history, or permissions.
```
